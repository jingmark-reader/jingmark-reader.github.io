Changelog

What's new in JingMark

Recent updates · New features, improvements, and fixes

Word (.docx) browsing and import

Latest

  • New Open .docx directly in a Word-like, read-only view — no Office or WPS needed.
  • New Convert a Word document into editable Markdown in one click. Large documents are converted in a Web Worker with progress visible.
  • Improved Native Word export maps Markdown to real Word objects (headings, tables, images), not pasted HTML.

Bring web content into your library

Recent

  • New Right-click any page, link, or selection to open it as Markdown in JingMark.
  • New Paste a Feishu / Doubao doc, WeChat article, or X (Twitter) thread in the address box to convert it to Markdown.
  • Improved X (Twitter) long threads and article reading view are extracted cleanly; WeChat articles keep lazy-loaded images and audio/video markers.
  • Improved Consecutive line breaks normalize into proper paragraph spacing.

Reading & writing core

Core

  • New 46 hand-crafted themes across 6 families, with code syntax highlighting that follows the theme.
  • New Interface in 13 languages, including right-to-left Arabic.
  • Improved Large documents (500KB+) open in read-only preview in under 500ms, with outline navigation and chunked rendering.
  • Improved WYSIWYG editing with auto write-back to the original file, split preview (narrow / medium / wide), KaTeX math and Mermaid diagrams.
  • Fixed Inline HTML in Markdown is now sanitized by default; trusted themes can opt in.

Privacy & performance

Core

  • Improved All libraries bundled locally under a strict Content Security Policy; no remote scripts.
  • Improved Startup JavaScript cut by ~65% via lazy-loading of docx, editor, and WeChat modules.
  • New Local-first: your files never leave your device.
