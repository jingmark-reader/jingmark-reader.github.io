يتضمن المجاني القراءة الكاملة لـ Markdown، 6 سمات مختارة، وتصفّحاً بجذر واحد. يفتح Pro كل السمات الـ46، وتصدير Word/PDF الأصلي، واستيراد Word .docx إلى Markdown قابل للتحرير، وتحرير WYSIWYG مع كتابة تلقائية، وإدارة مجلدات متعددة الجذور، وحفظ مستندات الويب، والمزيد. تبقى القراءة مجانية للأبد.

أي متصفح قائم على Chromium (Chrome وEdge وBrave وArc وغيرها) يدعم File System Access API (Chrome 86+).

انقر «ترقية» في الإضافة وسجّل الدخول ببريدك. تتم مزامنة حالة Pro تلقائيًا.

يرتبط Pro بحساب بريدك الإلكتروني ويعمل على 3 أجهزة كحد أقصى. على الجهاز الرابع لن تُفعَّل ميزات Pro — لن يتم تسجيل خروجك ولن تتأثر أجهزتك الأخرى. أزِل جهازًا غير مستخدم من لوحة الحساب لتحرير مكان.

نعم. يعرض JingMark معادلات KaTeX ومخططات Mermaid أصليًا — ما عليك سوى كتابة صيغة LaTeX أو Mermaid القياسية في Markdown الخاص بك.
